# Notebooks (Data & estimation)

Scratch space for exploring the data in `../Daten/`. Put anything reusable into
`backend/app/estimation/` so the API can use it.

Suggested first notebooks:
- `01_explore_liveticker.ipynb`: incidents, audit trail, reasons. How long do disruptions really last vs. what was announced?
- `02_similar_incidents.ipynb`: grouping by cause / line / time of day, quantiles of real duration.
- `03_intern_and_via.ipynb`: what the internal KULT ticker and VIA reports add.
